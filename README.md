# ai_skills

Personal collection of [Cursor Agent Skills](https://cursor.com/docs).

## Skills

| Skill | When to use |
| --- | --- |
| [explain-diff-html](explain-diff-html/SKILL.md) | Rich, interactive HTML explanation of a code change, diff, branch, or PR |

`explain-diff` is adapted from [ankitg12/explain-diff](https://gist.github.com/ankitg12/8e808d387799de4e9839bc393f8e6405) (originally [geoffreylitt/explain-diff-html](https://gist.github.com/geoffreylitt/a29df1b5f9865506e8952488eac3d524)).

## Install in Cursor

Copy or symlink a skill into your personal skills directory:

```bash
ln -s "$PWD/explain-diff-html" ~/.cursor/skills/explain-diff-html
```

Then ask Cursor to explain a diff, branch, or PR.
